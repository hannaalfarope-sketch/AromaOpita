# Aroma Opita ☕

## Descripción del proyecto

Aroma Opita es una página web de una cafetería
diseñada para presentar su identidad, historia,
menú y servicios.

El sitio permite a los visitantes conocer los
productos, consultar preguntas frecuentes y
contactar con la cafetería mediante un formulario.

## Tecnologías utilizadas

- HTML5
- Tailwind CSS v4
- JavaScript
- Google Fonts

## Características

- Diseño adaptable a celulares, tabletas y computadores.
- Menú de navegación.
- Modo oscuro.
- Sección de menú con imágenes.
- Preguntas frecuentes interactivas.
- Formulario de contacto con validación.
